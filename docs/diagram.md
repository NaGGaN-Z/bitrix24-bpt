# Диаграмма БП: проекция дерева в шейпе дизайнера Б24

Волна 7 (план внутренний план волны 7, 2026-10-15/16).
Статус: рабочий инструмент.

## Что это

`.bpt` → интерактивный HTML-просмотрщик (один файл, двойной клик, без
сети/npm) и статика (SVG/mermaid). Лейаут повторяет шейп дизайнера Б24:
хребет вниз, IfElse — бар условия + веер зон веток + merge-точка,
While/ForEach — рамка + левая пунктирная рейка «повтор», зелёные
капсулы «Начало»/«Конец». Референс — «похоже, не 1:1» (слово владельца).
Боевые шаблоны-пробники: два шаблона внешнего корпуса (103 и 118
акт.), booking-chain (дифф).

## Архитектура: «HTML-обёртка»

Единственный лейаутер — `bpt_diagram_runtime.js`, чистая функция без
DOM: `layout(tree, paint, foldState, opts) → {svg, coords, nodeIndex,
stats}`. Python (`bpt_diagram.py`) только парсит, красит и упаковывает;
node нужен ТОЛЬКО для статического SVG (вьюер — чистый HTML+JS).

- `load_tree(src, base=None, rename_map=None)` → JSON-контракт
  `{root, templateData}`; дети с `ghost:true` — призраки удалённого,
  интерколяция по порядку A сделана в python;
- `templateData` — Параметры/Переменные/Константы корня .bpt
  (PARAMETERS/VARIABLES/CONSTANTS). **DOCUMENT_FIELDS не рисуется**
  (поля документа, не данные шаблона — решение владельца);
- `paint_map(base, target)` → краска поверх `bpt_export.diff_templates`
  (identity-якоря, rename-иммунный — грабля project-x): added/modified;
  moved-узлы (identity+Title были в BASE, узел переехал в другой
  контейнер) — счётчик `moved=N` в сводке, БЕЗ краски; activated/sect
  не красят;
- `pack_html(...)` → один `.diagram.html`: runtime inline + JSON +
  бутстрап (свёртка, инспекция, блок данных, дифф-отчёт, зум, темы).

## CLI

```bash
python3 bpt_export.py diagram X.bpt [--diff BASE.bpt] \
    [--format html|svg|mermaid|d2|puml] [--out FILE|-] [--svg]
```

- **дефолт — html**; SVG только по запросу (`--format svg` или `--svg`
  дополнительно к html);
- `--diff BASE` — покраска (added/modified), призраки удалённого на
  ex-местах, дифф-отчёт в панели, сводка `+N −N ~N moved=N`;
- выходы: 0 ок / 1 ошибка / 2 usage; node нужен для svg, для html — нет.

## Вьюер

- ночная тема — дефолт, тумблер ☀/🌙 (день = warm-палитра);
- зум JS: колесо вокруг курсора, кнопки, drag-панорама; масштабируется
  только канва, панель props константна;
- клик по иконке ▾/▸ — свёртка контейнера/ветки; клик по телу —
  инспекция Properties (JSON-в-строке разворачивается, `\n` — реальные
  переносы); клик по чипу ветки IfElse — условия с джойнерами И/ИЛИ;
- блок данных слева: Параметры/Переменные/Константы, у UF:crm —
  «CRM-сущности» из `Options` (Y-ключи); клик — поля записи, при
  диффе — её изменения;
- безусловная ветка (нет cond-ключей или `truecondition='1'`) с
  дефолтным Title — подписывается «Истина», как в дизайнере.

## Грабли (боевые, все закрыты жгутом 19/19)

1. **XML-esc** в SVG обязателен: живые Title несут `&<>"` — единая
   точка `esc()` в runtime.
2. **`</script`-инъекция**: JSON в html инлайнится с `</ → <\/`.
3. **Шебанг** в inline-скрипте: hashbang легален только на позиции 0 —
   `pack_html` срезает строку `#!`.
4. **JS в питоновском шаблоне**: escape переноса в `_HTML_SHELL` пишется
   удвоенным — сырой байт `\n` рвёт JS-строку (канва пустая). В
   комментариях шаблона примеры escape-последовательностей запрещены.
5. **Данные ↔ рамки**: глобальный замер канвы учитывает `frameRects`
   наравне с узлами (рамки выступают влево на FRAME_PAD+RAIL_OUT —
   без этого наезжают на блок данных).
6. **Зум-лейбл**: сброс только через `setZoom(1)`, иначе проценты врут.
7. **Чужой дифф**: строка added/removed-события живёт только на корне
   поддерева — потомкам она чужая.
8. **Fold по иконке, инспекция по телу** — иначе ветку не прочитать.

## Ограничения и OPEN

- **ParallelActivity** корпусом etalons не подтверждён (образца нет) —
  эмит веером как IfElse без бара; это экстраполяция, помечено в
  докстринге и тесте.
- Rename-родителя призраки детей спасает только `rename_map` из
  `paint_map` (CLI-путь всегда передаёт; голый `load_tree(base)` —
  деградация «призрак старого + added нового»).
- Субтитры-значения под плашками деятельностей (как в дизайнере) — не
  делались (решение после мокапа; вход `subtitle` в контракте есть).
- moved-детекция по `identity_key+Title`: два РЕАЛЬНО новых узла с теми
  же identity и Title, что в BASE, посчитаются moved (multiset,
  дегенерат редкий).

## Тесты

`python3 tests/test_bpt_diagram.py` (или pytest): golden-снапшоты через
`node --json` на **тестовой** палитре (смена дефолтной золото не
ломает), SKIP если node нет; инварианты (пересечения/merge/свёртка);
unit краски и призраков; corpus smoke всех etalons; bootstrap
исполняется в vm и рисует канву.
