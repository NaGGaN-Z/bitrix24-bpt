# Probe-режим: runbook рантайм-прогона

Цель — увидеть фактические значения рабочих переменных после каждого
set_vars (рантайм-проверка SV-формул без боевого прогона и дизайнера).
Контракт журналирования — `etalons.md` «Probe-режим»; рантайм-факты и
грабли канала — скилл `bitrix24-bpt` references/probe-mode.md.

1. **Собрать дебаг-копию**: `python3 bpt_build.py probe TREE.json debug.bpt`
   — после каждого set_vars вставлен журналирующий timeline-комментарий
   (`[probe] after <Name>` + `ключ={=Variable:...}` на каждую переменную);
   OUT прошёл полный гейт save(). Исходник не мутируется, имена вставок
   без коллизий, детерминировано.

2. **Деплой — UI-импорт** `debug.bpt` (REST `template.add` закрыт
   ACCESS_DENIED, etalons.md). Импорт = upsert: дебаг-копия НЕ обязана
   ехать поверх боевого шаблона — после прогона удалить копию с портала
   (и помнить: AUTO_EXECUTE копии наследуется от исходника — автозапуск
   на создание/изменение сработает и у копии).

3. **Тестовая сущность**: любой CRM-документ с таймлайном (СП/лид/сделка),
   на котором можно запускать БП руками.

4. **Запуск**: UI-кнопка «Запустить бизнес-процесс» на сущности; REST-фолбэк
   для автоматизации — `bizproc.workflow.start` (TEMPLATE_ID импортированной
   копии, DOCUMENT_ID = `[<module>, <document_class>, <doc_id>]`; для СП
   doc_id = `DYNAMIC_<etid>_<itemId>`).

5. **Отчёт по переменным**:
   `python3 bpt_export.py probe ENTITY_TYPE ENTITY_ID [WEBHOOK_SRC]`
   — хронология «шаг / переменная / значение» (webhook: env `B24_WEBHOOK`
   или файл; URL в argv светится в `ps`). ENTITY_TYPE: `deal`/`lead`/… или
   `DYNAMIC_<etid>` для СП (голое число — 400); у тестовой сущности должен
   быть ответственный (без него таймлайн-комментарии молча не пишутся,
   см. etalons.md).

6. **Замыкание приёмки**: воспроизвести подозрительную формулу → в журнале
   видно фактическое значение ≠ ожидаемому → фикс дерева → повтор цикла.
   Многострочность probe-комментариев в таймлайне проверяется первым живым
   прогоном (при коллапсе строк — пивот джойнера, см. etalons.md).
